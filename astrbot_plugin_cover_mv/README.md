# 原神翻唱视频 AstrBot 插件

回复或引用一条包含音乐文件的消息，然后发送：

```text
/翻唱视频 角色名称 原唱作者 原曲名称
```

例如：

```text
/翻唱视频 珊瑚宫心海 周杰伦 晴天
```

角色、作者或曲名包含空格时使用英文双引号：

```text
/翻唱视频 芙宁娜 "Taylor Swift" "Love Story"
```

插件严格读取被引用消息中的音乐，支持 MP3、WAV、M4A、FLAC、AAC、OGG、OPUS；未引用音乐时不会创建任务。它会向映界服务的 `/api/cover-mv` 上传音乐，轮询任务状态，完成后把 MP4 发回原会话。

默认服务地址是 `http://192.168.100.1:18787`，由反向 SSH 隧道转发到
Windows 的 `127.0.0.1:8787`。AstrBot 在 Docker 中运行时不能把服务地址设为
`127.0.0.1`，因为那会指向 AstrBot 容器自身。
